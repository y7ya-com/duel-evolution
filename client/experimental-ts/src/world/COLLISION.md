`heightAt` compares exactly `ffff0000` and loads float32 at VA 0x00bf24c0 (file 0x7f24c0), otherwise VA 0x00be8198 (file 0x7e8198). They decode to .7f and 1.0f. The solver's inward increment at VA 0x00bedb70 (file 0x7edb70) decodes to .1f.

Resolved call targets establish every vector operation: 0x0040ea57 → footCenter 0x009cb280; 0x00408837 → footProbe 0x009caed0; 0x0040fa7e → vector addition 0x0060d700; 0x0040dd73 → subtract-in-place 0x0060d9e0; 0x0040d77e → vector subtraction 0x0060d770; 0x00406b4f → scalar multiply 0x0060d8c0; 0x0040e796 → add-in-place 0x0060d9a0; 0x00409d31 → isWall 0x00a50a00. Float-to-integer calls use CRT 0x00b09a80.

The solver behavior, independently expressed in TypeScript:

1. Compute candidate center and each ordered probe 0..15 as `(worldFoot + inputStep) - fieldOrigin`. Each vector helper stores float32 components separately. Samples truncate field-local XY toward zero after these stores.
2. For an initially blocked probe, form `inward = candidateCenter - candidateProbe`. Try `candidateProbe + inward * float32(j * .1f)` for j=1..9, storing the multiplied and added vectors separately.
3. At the **first free sample**, replace the selected correction only when this factor is strictly greater than the previous selected factor (initially zero). Equal factors retain the first vector/color. The selected color is the immediately preceding **blocked** sample's color, which may differ from the initial probe's color. It is not the free sample color or any arbitrary exit touched.
4. If all nine samples block, overwrite the correction with `-inputStep`, without updating the selected factor or color and without ending the outer loop. Thus a later equal-factor success cannot replace cancellation, but a greater one can. A later all-blocked probe can cancel an earlier successful correction while preserving its exit color.
5. Add the correction to the original input step once, with float32 component stores. Return true if any initial probe blocked. The `moveStep` speed cap/threshold and exit dispatch happen afterward, outside this solver.

Maximum reads are 160 per call; no retained solver state or mask references. `null` pixels throw `CollisionUnavailableError` with the sample coordinates, returning no partial movement/exit result. This deliberately replaces the original unsafe missing-pointer behavior with an explicit streaming wait condition. Callers must not convert the exception to a successful movement or exit. Geometry is caller-supplied actual engine root world geometry, not an avatar-centered guessed circle. XY-only displacement matches `moveStep`'s zero Z input; camera/depth handling is outside this API. Float32 vector stores and constants are modeled, but D3DX transform internals, x87 trig precision, and full bit-identical animation/movement playback are not established by these tests.

## API and ownership

Import directly from `./world/collision` and `./world/exits` (barrel integration belongs to parent):

- `rgbaMask(width,height,rgba,maxPixels?,signal?)` copies RGBA into an immutable callable `PixelMask`; exact unsigned ARGB values. `pixel` requires integer local coordinates, returns black outside.
- `decodeCollisionMask(pngBytes,{maxPixels?,signal?})` browser-only `createImageBitmap` + isolated canvas decode; accepts readable bounded archive bytes, no network or remote image URLs. PNG header geometry checked before decode; maximum encoded input 16 MiB, default 4 Mi pixels, hard maximum 16 Mi pixels. Result dimensions must match IHDR. Bitmap closes and canvas storage resets on success/failure/cancellation. PNG validity/CRC decoding belongs to the browser. Cancellation is cooperative: cannot stop native `createImageBitmap` mid-decode, but a late bitmap is closed and never returned. Browser decoding is not exercised against real masks here. Canvas may discard RGB under alpha=0; all special colors verified in samples/source are fully opaque, and transparent colors do not match wall/exit/height markers.
- `CollisionTiles(tileWidth,tileHeight,columns,rows,maxPixels?)` owns retained mask references, no I/O. `set`, `delete`, `clear`, `retainedPixels`, `pixel`. Logical tile stride from scene definition; natural image may exceed cell bounds and is never stretched. Aggregate default 16 Mi pixels, hard max 64 Mi; geometry max 8192/axis, columns/rows max16. Budget is checked atomically before replacement. Masks must be trusted immutable `PixelMask` implementations (use `rgbaMask`/decoder). Load/decode sequentially or with parent-owned bounded concurrency: store budget alone does not constrain concurrent temporary decodes. Call `clear` on scene change. No hidden cache/URL ownership.
- `heightScaleFromPixel(argb)` returns verified .7f/1f. `probeWalls(step, geometry, pixels, {fieldOrigin?})` returns immutable `{step,wallHit,color}`. Geometry has `{center,probes}` with exactly 16 ordered world-space pre-step points. `CollisionTiles` or `PixelMask` satisfies the pixel source interface. `CollisionUnavailableError` distinguishes missing streaming data. Origin defaults to (0,0), otherwise supply the actual field position at offset +0x70.
- `isWallPixel`, `exitIndexFromPixel`, `heightPixelRegion`, `footGeometry`, `smoothGroundStep`, `finishProbedStep` remain pure helpers. Smoothing/finish helpers use JS doubles and are not a bit-identical VC6 moveStep port.
- `crossingAt`, `detectExit`, `arrivalEntries`, `chooseArrival`, `CROSSING_REGIONS` are pure exit/arrival adapters to existing map metadata.
